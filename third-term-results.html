Third Term Results

Third Term Results نتائج الفترة الثالثة

Upload the school's grade workbook (one sheet per class) and generate official third-term result sheets.

📥 Upload Workbook  - رفع ملف الدرجات

Accepting a single .xlsx file. Each sheet in the workbook is one class (e.g. الأوّل التّحضيريّ، الأوّل الابتدائيّ، الثّاني الإعداديّ). Per subject the sheet must have the F, S, N, A sub-score columns (each /10), a 40 total column, a 60 exam column and the ف1 / ف2 / ف3 term-score columns. Student rows are S/N | Adm/Num | Student Name | scores.
Name: write both spellings in the one name cell (e.g. Amina Yusuf أمينة يوسف) — the result sheet automatically splits them: the English name at the top line, the Arabic name at the bottom line (never duplicated). An optional Arabic Name / الاسم بالعربية column is also recognised.
Note: the 40 and 60 columns are only used to work out T3 /100 (40 + 60). They are never shown on the result table, the PDF or the Excel export — only T1 /100 · T2 /100 · T3 /100 · AVERAGE /100 are reported.
Grand Total is every first-term 100 + every second-term 100 + every third-term 100 (a student offering 13 subjects has a maximum of 3900). Average = Grand Total ÷ (subjects × 3), so 3900 ÷ 39 = 100. Class position is ranked by that average.

✎ Signatures for Third Term Results  - التوقيعات لنتائج الفترة الثالثة

One Principal signature + one teacher signature per class (or shared Class Teacher fallback) are automatically stamped on every result sheet below. Manage / create signatures in the central tool:

Open Create / Manage Signatures

Per-class teacher signatures override the shared one for that class only. Update in Manage Signatures and regenerate to see changes.
